# NewClubCommuShow

新方式用の独立した配信ルートです。現在は**サンプル6動画による接続プレビュー**です。

旧 `data/`・`images/`・`videos/`・`ebk-room-media/` と旧生成Action、旧ワールドのURLは変更していません。Clubコミュ症の本番コンテンツはまだこのフォルダーへ移行していません。

- サンプル画像原本と動画生成コード: 非公開EBK。
- 公開テスト生成物: `tests/ebk-videoroster/groups/`。
- 新Action: **NewClubCommuShow VideoRoster preview**。各動画の世代とSHA256を検査し、このフォルダーへ公開テスト生成物をコピーします。新しい入力が届いた場合は古い生成物を公開しません。
- ウィザードの共通ルート: `NewClubCommuShow`。専用サンプル比較ボードで確認できます。sampleOnlyの動画を通常モジュールへ強制適用しません。
- 本番用の新動画/ManifestはサンプルワールドのUnity/VRChat確認成功後、このルート内へ追加する方針です。本番動画の新方式生成・全モジュールへの透過反映の完成を示すものではありません。

旧版へ戻す場合はワールド側で以前の接続先を選びます。旧データを新ルートへ移動/削除する必要はありません。
